# User Guide

## Desktop Orientation
- **Dock**: Launches applications, Appwrite Databases console, and the AI Copilot.
- **Windows**: Use the chrome to drag, minimize, maximize, or close. Focus a window by clicking on it.
- **Status Bar**: Monitor system health, tenant info, user identity switcher, and real-time Notification Center.

## Applications
- **Appwrite Databases**: Multi-tenant database manager, TablesDB schema inspector, and Server SDK code generator for 11 runtimes (Node.js, Deno, PHP, Python, Ruby, C#, Dart, Kotlin, Java, Swift, Rust).
- **Security Audit & RBAC**: Real-time immutable audit trail ledger with CSV/JSON exports and role-based access control governance.
- **App Store**: Install/launch enterprise micro-frontends with Native Federation.
- **AgentFS**: Manage sandboxed virtual filesystems with copy-on-write isolation.
- **WOPI Office**: Collaborative document editing (docs, sheets, presentations) with exclusive lock token acquisition.
- **AI Terminal**: Diagnostic tools and autonomous agent copilot.
