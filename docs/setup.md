# Setup Guide

## Local Development Environment

1. **Prerequisites**: Ensure you have Node.js (v20+), npm, and Angular CLI installed.
2. **Install Dependencies**: `npm install`
3. **Environment Variables**: Create a `.env` file based on `.env.example` and set your `GEMINI_API_KEY`.
4. **Run Server**: `npm start`
5. **Access App**: Open `http://localhost:3000`.

## API Key Configuration
- Gemini API Key is required for backend AI copilot functionality. Configure this in the Secrets panel in the AI Studio UI.
